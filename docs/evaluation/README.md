## The one thing to know

**Zero clips have a human reference.** The clips are cut, the system has been
run on all eight, the harness reports `unscored` for every clip and every rate
field is `null`, and no accuracy number for VaaniDesk exists anywhere in this
project.

Ground truth has to be produced by listening to the audio. A reference
generated by any model — including this project's own SraVaani reference
implementation and its 202 golden token ids — is a self-consistency check, not
ground truth, and the harness is built so that it cannot be scored as one.

The next step is one person, a set of headphones and `evaluation/ANNOTATION.md`.
Eight 90-second clips is about an afternoon for the text and a day for the
diarization.
